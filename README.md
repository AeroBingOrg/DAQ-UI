# DAQ-UI
DAQ-UI

Examples of PySide6 Code that we can use to learn how to make the eventual UI

PlotExample.py shows how to make plot widgets using pyqtgraph and RealTimePlot.py shows how to update plots in real time

Eventually will add a Layout.py which will show how to use PySide6 layouts, which essentially layout the widgets for you, which is probably what will be used for the final UI
